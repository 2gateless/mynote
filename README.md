# 📒 MyNote — 클라우드 동기화 & 온디바이스 하이브리드 AI 세컨드 브레인

**MyNote**는 빠르고 직관적인 마크다운 메모 관리와 **Google Firebase 실시간 동기화**, 그리고 **Google Gemini 기반 의미론적 벡터 검색(Semantic Search) 및 RAG(검색 증강 생성) 추론**을 결합한 개인 지식 관리(PKM) 웹 애플리케이션(PWA)입니다.

---

## 🚀 최근 주요 업데이트 (What's New)

### 1. ⚡ 0초대 고속 시동 & IndexedDB 영구 로컬 캐싱
- **IndexedDB 기반 메모 인덱스 전용 캐시 레이어 구축 (`notesCache.ts`)**:
  - 기존 `localStorage`의 5MB 용량 한계와 동기 JSON 파싱으로 인한 메인 스레드 멈춤(Jank) 현상을 완벽히 해결했습니다.
  - 전용 IndexedDB 스토리지(`mynote_cache_db` / `note_index`)를 도입하여, 수천 건의 메모가 쌓여도 앱 실행 즉시 로컬 캐시를 비동기로 복원하여 **0초대(즉각) 첫 화면 로딩**을 보장합니다.
  - Firebase 오프라인 지속성(`persistentLocalCache`)과 유기적으로 연동되어 네트워크 재접속 시 백그라운드에서 변경사항만 원활하게 실시간 동기화됩니다.

### 2. 📦 Vite 번들 최적화 및 청크(Chunk) 분할 · 동적 임포트(Code Splitting)
- **무거운 서비스의 온디맨드(On-demand) 동적 임포트 적용**:
  - **AI 시맨틱 검색 엔진 (`ai.ts`)**: 첫 화면 번들에서 완전히 분리하여, 사용자가 AI 검색이나 AI 설정을 호출하거나 백그라운드 임베딩을 실행할 때 동적 `import()`로 지연 로드합니다.
  - **이미지 뷰어 (`imageViewer.ts`)**: `requestIdleCallback`을 통해 초기 페인팅 이후 백그라운드에서 지연 초기화하여 첫 화면 렌더링 블로킹을 방지합니다.
  - **공유 유틸리티 (`share.ts`)**: 사용자가 공유 모달이나 상세 화면에서 공유 버튼을 클릭할 때만 동적으로 로드합니다.
- **번들 크기 대폭 경량화**:
  - 초기 진입 메인 번들 JS 크기를 기존 94KB에서 **70KB(gzip: 23KB)**대로 대폭 감축하였으며, `katex-vendor`, `markdown-vendor`, `ai`, `imageViewer` 청크가 명확하게 독립 분할되었습니다.

### 3. ⏱️ 검색 디바운싱(Debounce) & 저장 백그라운드 파이프라인
- **검색창 입력 300ms 디바운스 적용**:
  - 검색창에 글자를 입력할 때 매 타자마다 발생하던 필터링과 DOM 재렌더링에 300ms 디바운스를 적용하여 모바일 및 저사양 기기에서도 부드러운 타이핑 반응성을 제공합니다. (단, `Enter` 키 입력 시에는 대기 없이 즉각 AI 의미 검색이 발동됩니다.)
- **메모 저장 시 백그라운드 비동기 임베딩 파이프라인**:
  - 기존에는 저장 버튼 클릭 시 Gemini 임베딩 API 호출(1~3초)을 기다린 후 Firestore에 저장하여 지연이 발생했습니다.
  - 개선 후: 저장 버튼 클릭 즉시 Firestore에 메모와 인덱스를 먼저 저장하고 모달을 닫아 **사용자 체감 저장 속도를 0초대로 단축**시켰으며, 임베딩 생성과 벡터 필드 갱신은 백그라운드 비동기 파이프라인(`runBackgroundEmbeddingPipeline`)에서 조용히 처리됩니다.

### 4. 🛡️ PIN 보안 강화: 5회 오류 시 24시간 입력 잠금 및 이메일 긴급 통지
- **무차별 대입 공격(Brute-force) 방어**:
  - 잠금 메모의 4자리 암호(PIN)를 5회 연속 잘못 입력하면 즉시 **24시간 동안 암호 입력이 완전 차단**됩니다.
  - 잠금 모달 진입 시 남은 시간(예: `23시간 59분 42초`)이 실시간으로 1초 단위 카운트다운되며 키패드는 그레이스케일 처리 및 비활성화됩니다.
- **관리자 이메일(`2gateless@gmail.com`) 긴급 통지 & Firestore 감사 로그**:
  - 5회 연속 실패로 24시간 잠금이 발동되는 즉시 등록된 관리자 이메일(`2gateless@gmail.com`)로 발생 일시, 잠금 해제 예정 시각, 접속 기기 환경(User-Agent)이 포함된 긴급 보안 경고 메일이 발송됩니다.
  - 동시에 Firestore `security_alerts` 컬렉션과 `user_meta/{uid}`에도 감사 로그가 영구 기록되어 침입 시도를 즉시 추적할 수 있습니다.

### 5. 🧠 최신 AI 임베딩 모델 & RAG 종합 추론 고도화
- **최신 임베딩 모델(`gemini-embedding-001@768`)**:
  - `gemini-embedding-001`을 **768차원 고정(`outputDimensionality: 768`)**으로 호출하며, 배치 처리(`batchEmbedContents`) 및 지수 백오프 자동 재시도를 지원합니다.
- **한국어 형태소 분리 하이브리드 스코어링 & LRU 캐시**:
  - 조사·어미를 자동 분리하여 의미 벡터 유사도와 키워드 어근 매칭을 결합한 하이브리드 랭킹을 제공하며, 동일 질문 재검색 시 0ms 응답 LRU 캐시를 제공합니다.
- **장문 스마트 발췌 및 탐색 히스토리 스택 보존**:
  - 3,200자를 초과하는 장문 메모는 핵심 단락을 지능적으로 발췌하여 Gemini Flash 추론 프롬프트에 제공하며, AI 답변 내 `[[메모 제목]]`을 타고 들어갔다가 뒤로가기를 눌러도 AI 답변과 스크롤 위치가 그대로 보존됩니다.

## ✨ 핵심 기능 소개

### 1. 하이브리드 AI 의미 검색 & RAG 종합 추론
- **의미 기반 검색 (Semantic Search)**: 검색어와 정확히 일치하는 단어가 없어도, 질문의 맥락과 의도를 파악하여 가장 연관성 높은 메모를 찾아냅니다.
- **AI 종합 답변 (RAG Reasoning)**: 검색된 상위 메모들의 내용과 작성일 시계열 맥락을 바탕으로 **Gemini Flash**가 종합적인 답변과 인사이트를 제공합니다.
- **인용 메모 바로가기**: AI 답변 본문에 표시된 `[[메모 제목]]` 링크를 클릭하면 원본 메모로 즉시 이동하며, 탐색 히스토리 스택을 통해 원래 검색 화면으로 자연스럽게 복귀합니다.
- **IndexedDB 이중 캐싱 레이어**: 메모 인덱스는 `mynote_cache_db`에, 벡터 데이터는 `mynote_ai_vector_cache_db`에 영구 캐싱하여 Firestore 읽기 비용을 극소화합니다.

### 2. 강력한 마크다운 에디터 & 양방향 지식 연결
- **양방향 위키 링크 (`[[메모 제목]]`)**: 메모 사이에 내부 링크를 생성하고, 상세 화면 하단에서 현재 메모를 참조하는 **연결된 메모(Backlinks)**를 자동으로 모아 볼 수 있습니다. (대괄호 말머리가 포함된 메모 제목도 완벽 매칭 지원)
- **빠른 서식 도구 모음**: 제목(`H1`~`H3`), 굵게, 기울임, 취소선, 체크박스 할 일 목록, 코드 블록, 인용구, 구분선, 색상 강조, 수식(KaTeX) 렌더링 지원.
- **이미지 첨부 및 자동 압축**: 클립보드 붙여넣기(`Ctrl+V`) 또는 갤러리 선택 시 이미지를 적절한 해상도로 자동 리사이징·압축하여 저장하며, 더블클릭/핀치 줌 뷰어를 제공합니다.

### 3. 클라우드 실시간 동기화 & 보안
- **Google 계정 연동**: PC와 모바일 어디서나 동일한 Google 계정으로 로그인하면 실시간으로 메모가 동기화됩니다.
- **개별 메모 잠금 (PIN)**: 민감한 메모는 4자리 PIN(`Web Crypto SHA-256 + Salt` 해시 보호)으로 잠가 목록 미리보기, 로컬 캐시, AI 추론 노출을 철저히 차단합니다.
- **무차별 대입 방어**: 5회 오류 시 24시간 잠금 및 이메일 긴급 통지로 기기 분실 시에도 메모 유출을 원천 방어합니다.

## 🛠️ 시작하기 및 AI 설정 방법

### 1. 로컬 개발 환경 실행
```bash
# 의존성 패키지 설치
npm install

# 개발 서버 실행 (http://localhost:8092)
npm run dev

# 프로덕션 번들 빌드
npm run build
```

### 2. Gemini API 키 설정 (`⚙️ AI 설정`)
1. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료 **Gemini API Key**를 발급받습니다.
2. MyNote 상단 검색 영역의 **`⚙️ AI 설정`** 버튼을 클릭합니다.
3. 발급받은 API 키를 입력하고 **저장**을 누릅니다.
   - **로컬 단독 보관 (기본값·보안 권장)**: API 키가 현재 기기의 브라우저(`localStorage`)에만 저장되어 안전합니다.
   - **클라우드 동기화 (선택)**: 체크박스를 켜고 저장하면 HTTPS 통신을 통해 본인의 비공개 Firestore 경로(`user_meta/{uid}`)에 저장되어 다른 기기에서도 별도 입력 없이 즉시 연동됩니다.
4. 기존 메모에 대한 벡터를 일괄 생성하려면 하단의 **`🔄 기존 메모 일괄 변환 시작`** 버튼을 클릭합니다.
